Under the hood

What the dashboard runs on.

Platform OAuth

Instagram, TikTok, X, YouTube and Facebook connect through their own logins. Reach is read, never scraped.

Revenue attribution

Promo codes, tagged links, affiliate pages and retailer sales feeds tie every order back to the partnership that drove it. Media value is reported alongside, labelled EST.

Verified handle registry

Seeded ground truth for national teams and franchises, so a fake account never inflates a value.

Briefs marketplace

Two-sided: brands post, athletes and teams apply, terms agreed on the platform, return measured from day one.

Report library

A4 PDF editions generated from the same data layer, one currency per report, sources listed.

Payments and API

Card payments through Paystack. Reporting API for brands and agencies on request. POPIA controls on every personal record.
